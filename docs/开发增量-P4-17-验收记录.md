# P4-17 单会话消息正文搜索 API

## 范围与基线

沿用户持续开发授权，优先推进 P4 未完成的搜索能力。基线 P4-16 提交 `f6609e04d509f40736f6a882a2b7cea36d14037a` / 草稿 PR #63；分支 `codex/p4-17-message-search`，复用既有隔离工作区。首个切片为单聊／群聊单会话正文搜索 API，无迁移。本增量不等同于完整 P4 搜索验收。

## API 合约

- `GET /api/v1/conversations/{id}/messages/search?q=关键词&limit=20&cursor=...`
- `GET /api/v1/groups/{id}/messages/search?q=关键词&limit=20&cursor=...`

沿用 Bearer 令牌与 `X-Acting-Membership-ID`；租户和用户来自认证。`q` 必填，有效 UTF-8、无 NUL，去除首尾空白后 2～100 字符。以 Unicode 小写转换后的字面子串匹配，不提供分词、模糊、拼音、正则或 SQL 通配语义；百分号、下划线和反斜杠均按字面匹配。`limit` 默认 20、1～50；省略游标查询首页，显式空游标、超过 2048 字节游标、重复／未知参数、非法编码和 GET 正文均拒绝。

成功响应包含 `conversation_id`、`messages`、`has_more`、`next_cursor`，数组为空时为 `[]`，末页游标为 `""`，响应 `Cache-Control: no-store`。每条匹配包含 `id`、**十进制字符串 `seq`**、`sender_user_id`、`text`、`server_time`，不会返回 redacted 占位。字符串序号避免 JavaScript 超过安全整数后丢失精度。

参数／游标错误 400 `invalid_search`；未认证 401；账号／任职失效 403 `invalid_identity`；非参与人、从未入群、不存在或跨租户会话 404 `not_found`；数据库、审计或事务提交失败 503 `unavailable`。应用拒绝日志不写查询串，搜索审计不写关键词或正文。

## 搜索与授权

复用历史读取事务，在正文可见性判定后匹配；不会先用关键词筛选隐藏正文。单聊沿发送时的双方任职和组织快照；群聊沿加入／退出序号区间、有效发送者任职及群级 hard_deny。退群与再入群的间隔、无法证明历史授权的旧消息、到期和物理清空的正文不会出现在结果中。`policy_blocked` 的已授权历史仍按既有规则读取；法务保全仅暂停清理，不扩大搜索可见期。

搜索事务显式 READ COMMITTED；沿用身份关联行、租户保留期和会话锁，搜索群聊同时锁当前策略指针。锁等待后按新时间校验；正文可见性沿用历史读取事务的最后授权判定时点，随后登记审计并提交。成功读取与 `message_search` 审计同事务，原因分别为 `direct_search_page` / `group_search_page`；失败不返回匹配或续查游标。普通补拉保持原 `message_pull` 审计及 API 合约。

## 有界分页

按 `seq` 升序检查最多 500 条历史消息，既有读取再取一条探测后续记录。只匹配已授权正文，并按 `limit` 返回；匹配数达到上限且仍有匹配时，下页从最后已交付匹配继续，避免跳过结果。其余情况下从本次检查的最后序号继续。

**`has_more` 表示尚需续查，不承诺还有匹配。** 本页可能 `messages:[]` 且 `has_more:true`，客户端必须保留游标继续搜索，直到末页；不能把空页解释为整个会话无匹配。不提供总命中数。进度来自会话时间线，不依据隐藏正文是否命中，避免隐藏内容推断。

游标绑定租户、用户、当前任职、会话、单聊／群聊类型及规范化关键词，序号使用字符串。更换这些条件必须从首页查询，UUID／关键词大小写及首尾空白的等价输入可续查。游标是规范编码的进度数据，不是授权凭证；每页重新复核身份与历史权限。跨页无共享快照，权限、到期或清理变化会影响后续结果，新消息须重新查询核查。
