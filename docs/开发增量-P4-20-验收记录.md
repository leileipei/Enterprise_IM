# P4-20 Web 跨会话文本搜索验收记录

## 确认范围

用户于 2026-10-04 确认短设计：侧栏“搜索历史消息”，在当前有效任职下搜索本人可读取的全部／单聊／群聊历史；展示会话类型、会话 ID、消息序号、正文、发送者 ID 和时间；空页续查、首页刷新、上下文清空及迟到响应防护。沿用现有页面流程，按 bounded 增量实施，无新生产依赖／数据库迁移。

基线为 P4-19 `e40224888df73a6c43582ce5664932c44c31d499`，依赖 [API 草稿 PR #67](https://github.com/leileipei/Enterprise_IM/pull/67)。本轮独立分支 `codex/p4-20-web-cross-message-search`。

## 页面行为

- 侧栏全局入口选择有效任职后显示，未选择聊天也可使用。打开弹窗不自动提交空关键词；范围默认“全部”，可切换“单聊／群聊”。
- 使用现有可信 request 函数携带当前任职与访问令牌，GET `/api/v1/messages/search`，q／kind／limit=20／cursor；不枚举会话、不追加授权范围。
- 前端与 Go 的空白及简单小写一致，涵盖 NEL、保留 FEFF、İ 和希腊 sigma；输入 2～100 Unicode 码点，正文作为 textContent 安全展示。
- 每次在追加前整页校验消息数组／上限、UUID、类型／范围、序号规范字符串与 int64 上限、正文 UTF-8 长度及字面匹配、真实日期、has_more／游标一致性和循环。
- 顺序按会话 UUID／seq 比较；BigInt 无损序号。不同会话可以同 seq 或 seq 重新从 1 开始，同会话的序号必须严格递增；消息 ID 跨页去重，会话类型一致。异常页整页清空，不能先展示部分响应。
- 只复制并展示已定义消息字段，不推断会话名称／对端姓名，不添加定位／发送动作。结果与同步时间线独立，只保存在页面内存。
- 改词／改范围立即取消请求并清空结果，不自动查询新范围。关闭／Esc、切换任职、聊天上下文重置、注销／登录失效清空关键词、游标、结果并恢复默认范围。
- 请求代次、身份和原始输入／范围快照阻止忽略 AbortSignal 的迟到响应回填。每次请求 15 秒 timeout，错误允许首页重试；invalid_identity 撤销任职，401 沿既有流程退出登录。
- 空页有游标时明确允许继续查询；“刷新，从头查询”重建搜索。只展示已返回条数，已走过区域新消息须首页刷新。
