## 固定工具与SDK查找

本任务仅使用进程级DEVELOPER_DIR，不运行全局xcode-select。固定objective_c的构建钩子经过hooks_runner过滤环境，单纯设置DEVELOPER_DIR不能传入钩子；全局仍为CommandLineTools时会找不到iOS SDK。本轮用任务私有PATH的xcrun转发器解决，内容如下：

```sh
#!/bin/sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
exec /usr/bin/xcrun "$@"
```

将该文件保存为独立私有工具目录中的xcrun、chmod700，只在本次命令PATH最前使用。保持SDK／包缓存为工程外绝对路径，不修改锁定插件或全局设置。先在客户端目录执行锁定SDK的pub get --offline --enforce-lockfile，再以相同任务环境执行：

```text

<固定SDK>/bin/flutter test integration_test/mobile_lifecycle_test.dart -d <自有模拟器UDID> --no-pub
```

本轮mobile_lifecycle_test只测试真实活动场景，不自动按Home或模拟后台，不代表挂起／恢复／设备重新准入已完成。移动端使用resumed作为活动焦点，desktop仍要求view focus；后台及inactive均停止可见性，授权blocked状态不会因此清除。
