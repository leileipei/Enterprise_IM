# P4-08 Web 法务保全状态查看

## 范围与基线

在已批准的会话级法务保全模型上，继续接入现有查询 API 的 Web 界面。基线 P4-07 `dd79aa0` / 草稿 PR #54，分支 `codex/p4-08-web-legal-holds`，沿用原隔离工作区。无数据库迁移，无清理 Worker 配置变更。

## 功能与合约

- 选定任职经既有租户保留期管理接口完成集团管理员检查后显示“法务保全”。网络／5xx 检查失败提供“重试保全权限检查”；普通员工与组织管理员不显示入口。记录与保全两个控制器分别探测权限，每次身份变化各一次；服务端仍对每页查询鉴权。
- 查询当前选中的单聊／群聊 `GET /api/v1/admin/conversations/{id}/legal-holds?limit=20&cursor=...`，无 cursor 表示首页；每页最多 20 项，按服务端登记时间／ID 升序，后续使用原游标。刷新清空后重新查询首页。
- 展示保全 ID、案件引用、登记人员与任职 ID、登记时间。解除时间、审批引用及解除人／任职完整时显示“已解除”，无解除字段则显示“保全中”。时间按浏览器本机时区。
- 当前页不代表全部状态，后续页可能仍有有效保全；页面逐项显示并提示继续加载核查。仍有任一项有效时，前序 Worker 设计会暂停该会话正文／摘要清理。保全不改变到期正文的读取遮蔽，引用仅记录不核验外部审批结果。
- 校验列表／游标、UUID、会话匹配、案件和审批引用、登记时间、完整解除字段及解除时间顺序；拒绝重复 ID、循环游标、空页继续游标。错误不保留部分显示结果。
- 记录只在当前页面内存保留白名单字段，全部 textContent 渲染，不存入 localStorage／sessionStorage。切任职、切会话、关闭和退出清空，身份／会话 epoch 与请求 generation 共同丢弃旧响应。
- 查询 403／404 清空并禁用保全入口；401 按原请求流程退出；503、网络故障及非法响应清空后可刷新重试。已显示数据在后续请求收到失权响应时清空，不宣称服务器撤权瞬间自动消失。

## 验证过程

1. 浏览器用例先因缺少法务保全入口失败，静态资源安全头用例先因 `/web/legal-holds.js` 404 失败；实现后通过。首版卡片缺少新的语义类名造成测试定位失败，修正后状态／字段断言通过。
2. 真 Chrome 配合确定性 HTTP 边界覆盖普通身份、解除审批与人员、后续页有效保全、分页、空页、503、非法解除字段、会话错配、循环游标、重复 ID、会话／任职延迟响应、群路由、403／404、401与手机布局。
3. 两个控制器探测分别返回 503，点击保全权限重试后入口恢复；第二个（保全）探测被延迟，切普通任职后回包不能恢复入口。
4. 真实链路使用生产 im-api／Outbox Worker、本地 HTTPS OIDC PKCE、PostgreSQL／Redis 和 Chrome。测试通过真实 access.Service 登记两项保全、解除其中一项；浏览器查询显示已解除及有效状态、审批引用，数据库断言 legal_hold_list 允许审计一条。继续原清理批次、实时通知及离线恢复流程。没有启动正文或摘要清理 Worker。
5. 桌面 1280×850、手机 390×844 截图检查，修正关闭按钮挤压换行；手机长列表可滚动到完整边界说明，ID 与长引用换行显示。

## 最终结果

完整 `go test ./... -count=1 -v`：404 个顶层 PASS、0 FAIL，唯一 SKIP 为多进程测试辅助入口 `TestRealtimeAPIChild`。真实浏览器及双生产 API 集成用例明确 PASS。十个既有独立浏览器流程全部通过，P4-07 清理记录测试继续通过；`go vet ./...`、`go build ./...`、JavaScript 语法、`git diff --check` 通过。

独立评审与当前差异复查：Critical 0、Important 0、Minor 0。评审初检发现新控制器的权限探测失败和旧探测回包未覆盖，已补充并通过。最终全套数据库／浏览器回归由实现方执行。

评审另考虑并保留以下边界：严格 RFC3339 校验沿用前序日期解析惯例；两个控制器分别探测已明确记录；网络请求取消属于资源优化，现有代次检查保护展示结果；404 后禁用按本次交互约定执行；测试用既定调用次序暂停第二个权限探测，不以运行时私有状态作验收；登记／解除及外部审批联动留待后续增量。

专用 PostgreSQL 16 / Redis 7 端口 32939 / 32940；集成测试每个用例隔离 schema。本机临时日志 `/private/tmp/enterprise-im-p4-08-*.log`，截图 `/private/tmp/enterprise-im-p4-08-visuals/`，不作为永久证据库。

## 验收边界

本增量只读，尚未提供 Web 登记／解除保全、保留期编辑、任意会话 ID 检索或证据导出。保全模型及清理算法仍沿用前序实现，页面查询不能证明备份、WAL 或外部副本已擦除。客户身份源、代理、浏览器兼容性及容量仍需客户环境验收，尚未部署或合并。
