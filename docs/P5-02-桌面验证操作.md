SDK必须为Flutter源码e8113bf45620cbeb8aff64947ee4c93e16adb4cf，已跟踪文件无改动。保留客户端锁文件并先执行flutter pub get --enforce-lockfile；使用已准备缓存时可加--offline。工程外的SDK／cache目录由操作者管理，不使用全局flutter config或xcode-select改变其它项目。

## 2. Windows启动门禁

使用PowerShell7、本机Windows x64、Visual Studio的Desktop development with C++工具链和Windows SDK。专用一次性OS测试账号中不得有真实IM服务、账号或保存的凭据。正常启动会读取该账号的应用配置／安全存储；不可在个人已登录账号中执行此门禁。脚本不删除用户账号缓存或凭据。

在仓库根执行：

```powershell
./scripts/build-client-windows.ps1 -FlutterSdk <固定SDK绝对路径>
./scripts/test-client-windows-startup.ps1 -Executable ./clients/enterprise_im/build/windows/x64/runner/Release/enterprise_im.exe -Output ./startup.json -IsolatedTestAccount
```

门禁实际启动同一个固定摘要的`.exe`。无参数应出现窗口，正常关闭实际退出0；8组自有假参数应在10秒内实际退出1，含token、拆分token、业务HTTPS／本机回调／custom URI、文件路径、空参数及不支持的COM冷启动参数。失败或超时只清理本次由脚本启动的Process；报告逐项退出码、强制清理及失败，不能把清理后的退出码记成业务PASS。解析失败／异常argc仅能由宿主入口夹具验证，Windows原生参数解析另由此门禁覆盖。

结果仅证明启动边界／窗口启动，不验证登录、IME、回执、系统通知显示或真实后端。所有参数为假输入；不得把真实令牌、回调code或秘密放入命令行。

## 3. 原生回调与系统安全存储

在客户端目录以固定SDK执行：

```text
flutter test integration_test/desktop_lifecycle_test.dart -d windows --no-pub
flutter test integration_test/desktop_lifecycle_test.dart -d macos --no-pub
```

该入口只测试编译后桌面应用的真实127.0.0.1回调取消／端口关闭及旧回调不可重新打开。它不注入窗口事件，也不证明最小化、焦点或真实后端恢复，文件名不是验收范围。

生成一次全新的随机64字符hex命名空间（32字节，不是账号或认证秘密），以相同ID启动两个独立原生进程：

```text
flutter test integration_test/secure_storage_test.dart -d <windows或macos> --no-pub --dart-define=IM_VAULT_PROBE_ID=<全新64字符hex> --dart-define=IM_VAULT_PROBE_PHASE=write
flutter test integration_test/secure_storage_test.dart -d <windows或macos> --no-pub --dart-define=IM_VAULT_PROBE_ID=<同一ID> --dart-define=IM_VAULT_PROBE_PHASE=verify
```

write拒绝覆盖已有值；verify校验自有marker后删除该记录并复读为空。无论write步骤结果，均尝试verify以核实所属记录清理；失败时不得声称已清理，记录该命名空间待人工核实。不得deleteAll或清除其它访问组／账号。单个write进程中的读回不能替代重启验证。未准备开发证书的macOS不应关闭沙盒／移除Keychain权限以获取PASS。

Xcode许可已通过，当前开发证书数量0。操作者在Xcode Accounts准备Apple Development证书并选择预期开发团队；本工具不创建证书或导入私钥。可以为当前进程提供固定SDK支持的FLUTTER_XCODE_DEVELOPMENT_TEAM、FLUTTER_XCODE_CODE_SIGN_IDENTITY构建变量，不将团队或证书选择写成其它项目的全局配置。CI的macOS job要求专用self-hosted／macOS／ARM64／enterprise-im-desktop-isolated runner预先准备SDK、cache、证书及这两个变量；不存在时应失败，不退回禁用签名。

```text
IM_FLUTTER_SDK=<固定SDK> /bin/bash scripts/build-client-macos.sh
```

真实签名、运行、沙盒网络／Keychain／系统选择器／通知需独立验证。已有compile-only产物不安装或分发。开发证书签名与Developer ID发布签名／公证分开报告。
