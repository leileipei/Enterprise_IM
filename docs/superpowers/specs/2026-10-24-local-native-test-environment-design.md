让现有普通Android Release APK及iOS模拟器Debug主入口在本机可重复执行系统浏览器登录、任职选择、两个测试账号的消息／设备送达／已读；保留原始构建来源与包摘要。第一阶段只做消息与回执，附件依赖MinIO/ClamAV及业务配置，另行推进，不承诺本短设计完成附件矩阵。

固定源 `487cce9f4a74602cf36ffccf14d64fb31d513568` 上，已用现有自动化夹具实际通过3项后端测试：NativeOAuthExchangeThroughRealAPIIdentityMapping、ProductionAPIWithOIDCAndRealtimeProcesses、ReceiptWorkerCrashReplayTwoAPIProcesses。真实PG/Redis/API/Worker及合成HTTPS身份源可运行；结束已全部回收。该证据没有系统浏览器登录或普通包业务验收。

## A的拟定实现

1. 复用锁定PostgreSQL、Redis与未修改的Go API/Outbox/Receipt Worker；仅新建带owner/source标签的隔离测试容器、数据库和回环端口，不读取或写入既有数据库。运行工具提供启动／状态／停止，具有明确租期；租期结束仅回收本次所有资源，保留脱敏证据。失败时保留归属账本及可恢复状态，不执行全局清理命令。
2. 独立的测试专用身份源与API HTTPS前端，入口显著标记“本地合成身份源”。只选择预置Alice/Bob合成人员，不接收客户密码；不向生产API增加免密或测试认证分支。持久化OIDC public-client配置、JWT at+jwt受众／client_id、一次性短期code、S256 PKCE、state／nonce、固定回调及旋转refresh必须经过对应正反例验证。
3. 每个环境新生成独立短期测试CA与服务器密钥，不复用Go httptest公开静态测试私钥。API前端及身份源都使用该CA；回环SAN及模拟器端口映射精确绑定。私钥、口令、token只留私有0700目录／0600文件或进程内存，不进Git、测试包、通用日志或交付压缩包。
4. 首先新建两台项目自有Android API36模拟器，使用独立ADB服务并关闭USB／自动发现。若需要使未修改Release信任本地CA，只允许本次AVD私有可写镜像／覆盖层中的系统CA变更；允许该自有虚拟机内为此使用guest root/remount/reboot，禁止修改SDK基础镜像或真实手机。基础镜像及APK摘要在前后必须一致。
5. iOS只允许本项目新建、精确UUID绑定的模拟器中增加该CA；不改Mac登录/系统钥匙串、真机或已有模拟器。CA指纹、模拟器UUID/AVD路径、所属进程及有效期写入非秘密审计；结束删除本次模拟器及其信任。
6. 不重新签名、重新构建或放宽现有普通Release的TLS校验；不能使用badCertificateCallback全放行、忽略HTTPS错误、全局证书策略或对客户域名的信任覆盖。若隔离镜像或精确CA信任无法证明，则该平台保持未验收，不切换为弱化安全的通过条件。

## 新增授权边界（需要明确同意）

既有验证范围保持“不改OS信任／不guest提权”。A首次引入了**仅限本项目新建模拟器**的CA信任，及为其对自有Android虚拟机的guest root/remount/reboot。因此需要批准本短设计和该新增范围后，才编写实施计划并执行。Mac系统／登录钥匙串、用户已有模拟器、真机、SDK基础镜像、客户SSO和生产环境始终不在此授权范围。

## 验收及失败保留

- 原APK／主入口产物完整摘要、CA指纹、owner/source、各模拟器身份及基础镜像前后摘要必须可核对。
- 实际系统浏览器展示合成身份页、回调回App；错误state／nonce／PKCE、重复或超时代码必须拒绝。
- 两个独立普通应用进程完成发送、逐设备送达、可见已读及断线补拉，独立数据库事实与发送端显示对应。
- 有效通过仅限本地合成身份源及相应产物，不补客户SSO、MFA、真机、Windows、macOS签名、公证或生产验收。
- 所有失败尝试原样保留；停止后核对所属进程、容器、端口、私有凭据目录及模拟器已回收，保留证据。未明确启动长期服务前不称“环境已部署”。
