# P4-13 Web 管理审计查询

## 范围与基线

基于 P4-12 `67cc654db947ca0414cb28732fde5c97707727a5` / 草稿 PR #59；分支 `codex/p4-13-web-audit`。复用已附加隔离工作区和现有 `GET /api/v1/admin/audit-events`，新增管理员侧栏只读查询弹窗与控制器。本次没有新增 API、迁移、写入动作或审计清理任务。

## 页面与查询

- 复用既有集团管理员保留期权限检查，成功后显示“管理审计查询”。无需选择会话；服务端仍每次复核当前身份和授权，入口显示不是授权凭据。
- 动作代码可留空，或者填写 1～64 个小写字母、数字、下划线，以字母开头；选择全部／允许／拒绝结果。点击查询或刷新从首页读取；每页 20 条，使用服务器游标加载更多。
- 输入或选择筛选变化立即清空旧列表、游标并作废旧请求；新查询不使用旧筛选的游标。合法未登记的动作显示空记录；非法动作不向接口发送查询。
- 卡片只显示事件 ID、允许／拒绝、动作、执行人及任职 ID、资源类型／可空 ID、原因代码和时间。资源 ID 为 null 时显示“未指定”。本机时区时间之外保留原始 RFC3339 时间以展示完整小数精度。
- 通过 textContent 展示文本，仅在页面内存保存接口白名单字段；未把响应额外正文／摘要写入列表或存储。不提供编辑、导出、回滚或删除。

## 分页精度与异常处理

- 严格校验事件数组、每页数量、字符串游标、DTO 字段类型、UUID、正数 bigint 十进制字符串和 64 位范围，以及真实日历 RFC3339 时间。拒绝数字型 ID、前导零、越界值、无效资源、非法结果及筛选不匹配的响应。
- 用 BigInt 比较事件 ID；原始时间的小数补足 9 位后与整秒 UTC 时间合成整数键，避免 Date.parse 毫秒精度使纳秒／微秒同页顺序误判。
- 同页和跨页按 `(occurred_at,id)` 严格降序，检查所有已加载 ID 去重；拒绝逆序、重复、游标循环和无边界续页。新游标存在时必须是一整页，末页为空游标。
- 每次请求 15 秒等待上限。失败或异常 DTO 清空全部已显示记录与游标，刷新从首页重新读取；不保留半页证据。
- 关闭／Esc／任职变更清空结果和筛选，递增请求代次；迟到回复不能恢复旧身份／旧弹窗／旧筛选内容。401 沿用认证重置退出；403／404 清空并禁用查询，隐藏审计入口。
- 若保留期或法务保全写入结果待确认，点击审计入口重开原核对窗口，不发起新的审计查询；保留既有写入保护。

## 验证证据

- 改动前完整基线通过。启动专用容器后核对当前 PostgreSQL 33105、Redis 33106 端口。
- 真实 Chrome 加载生产 HTML／JS 的新增用例先因“缺少审计入口”失败；实现后通过。23 条记录包含超过 JavaScript 安全整数的 ID、亚毫秒不同时间且 ID 反序、HTML 形状文本和 null 资源。
- 覆盖两页加载、动作／结果筛选、空结果、非法动作不请求、数字／越界／前导零 ID、重复／逆序／跨页异常、无效日历、资源及结果字段、筛选逃逸、游标循环、503、403、404、401和真实 15 秒超时。
- 覆盖延迟回复后改变筛选、关闭、切换任职；未知保留期写入无法被审计入口绕过；只读查询期间写入计数为 0。故障注入位于 HTTP 边界，使用生产页面逻辑，不以模拟 UI 替代真实控制器。
- 独立评审指出只比较当前游标不足以拒绝跨多页循环，且合法大整数样本被其他样本覆盖。补成三个完整页、唯一且严格降序记录、空→A→B→A 游标链；修正前页面错误接受 60 条，用例实际失败。控制器加入本次查询的游标集合，在刷新／筛选／关闭／身份变更／失败时重置；返回已见游标即拒绝并清空。合法样本现包含同时间 9007199254740993／9007199254740992，另有逆序拒绝用例。
- 本地 HTTPS OIDC PKCE、生产 im-api / Outbox Worker、真实 PostgreSQL／Redis 和 Chrome：页面实际修改期限为 180 天，再验证有消息时延长被拒绝；审计页面筛选出一条 approved_retention_change 允许事件与一条 retention_extension_requires_empty_history 拒绝事件，关闭后清空。数据库核对三条允许查询审计。既有审批历史、法务保全、多设备通知及离线恢复继续验证。
- 已查看桌面与 390px 手机截图，长 ID、原因、时间可换行，弹窗可滚动且没有横向溢出。操作结果选择控件随后统一为现有表单样式，最终完整测试使用更新后的页面。

## 边界

查询只覆盖在线库已登记的 audit_events，不包含规则命中明细、审计导出、外部审批核验、完整性签名或审计到期清理。查询本身也登记审计，本页不包含自身事件，后续无筛选查询可能看到它。跨请求没有共享快照，新增或迟到提交事件需刷新核查。未启用正文／摘要清理 Worker；客户身份源、证书、代理、浏览器兼容性与生产容量仍需验收。草稿 PR 不代表合并或部署。
