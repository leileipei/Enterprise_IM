## 启动、状态与停止

第一个终端运行前台监督器；保留窗口直至停止或租期到期：

```bash
cd '/Users/leo.cui/.codex/worktrees/p5-02-native-clients/企业IM系统'
IM_LOCAL_STATE="/private/tmp/im-local-manual-$(date +%Y%m%d-%H%M%S)"
/usr/bin/python3 scripts/run-local-native-env.py start \
  --state-dir "$IM_LOCAL_STATE" \
  --go /opt/homebrew/bin/go \
  --lease-seconds 1800
```

租期最多 14400 秒，从创建状态开始计时，包含准备时间。只有生产进程、严格 HTTPS health 和四平台配置确实就绪后才输出 `status=ready`。就绪信息给出本次 `origin`、`issuer`、CA 路径 / 指纹、owner/source 及资源标识，不含凭据。

在第二个终端使用第一个终端实际输出的状态目录：

```bash
/usr/bin/python3 scripts/run-local-native-env.py status --state-dir /private/tmp/本轮实际目录
/usr/bin/python3 scripts/run-local-native-env.py stop --state-dir /private/tmp/本轮实际目录
```

`status` 只读。`stop` 写入与 owner/source 及监督进程完整指纹绑定的停止请求；SIGINT / SIGTERM 和租期到期也进入回收。停止后保留私有状态、资源账本及脱敏证据，删除本轮运行凭据和私钥目录。

若返回 `recovery_required`，说明原监督器已消失或其 PID 身份不符。不要向该 PID 盲目发信号或删除目录；保留账本供精确归属复核。清理失败也保留恢复材料。

## 模拟器与客户端边界

库入口 `scripts/integration/local_env_simulators.py` 提供私有系统镜像复制 / 校验、精确环境 CA 验证和 `prepare_ios`。iOS 入口验证固定归档摘要，只能创建新的随机归属名称、精确 UUID，调用该 UUID 的 `simctl keychain add-root-cert`，并逐文件核对安装包与归档。当前通用 CLI 只管理后端；模拟器由本轮受监督验证 helper 调用，尚未形成通用一键双端命令。

Android 仅在经过 owner/source、私有路径及前后摘要校验的副本上启用 `-sysdir` / `-writable-system`；默认模拟器参数不变。首轮 API36 / API24 探测没有执行 guest root 或 CA 安装，也没有将 WebView Shell 算作系统浏览器。后续仍需明确、可复现的真实浏览器条件。

不要向 Mac 系统 / 登录钥匙串、真实设备、已有模拟器或 SDK 基础镜像导入测试 CA。不要绕过 TLS 错误、改签或重建普通 APK，或向主应用注入验证配置 / 测试入口。
