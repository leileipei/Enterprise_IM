# P4-10 Web 消息保留期配置

## 范围与基线

承接 P4-09 后的 Web 消息保留期配置增量。基线 `d1385e7` / 草稿 PR #56；分支 `codex/p4-10-web-retention-policy`，沿用已附加的隔离工作区。复用 P4-02 已有的租户级 `GET/PUT /api/v1/admin/retention-policy`，没有新增数据库迁移、审批系统集成或清理任务启用。

## 页面与业务规则

- 复用清理记录模块已有的集团管理员权限检查；管理员可在未选择会话时打开侧栏“消息保留期配置”，其余任职隐藏入口。服务端仍在每次读取／写入时重新检查权限。
- 显示当前正文期限、版本、审批引用、审批登记人 ID 和本机时区的登记时间；版本 0 明确为默认 365 天且没有变更审批。
- 填写 1～3650 天的整数和已取得的审批引用。引用去除首尾空白后按 Unicode 码点计 1～128 字符，拒绝控制字符、孤立 UTF-16 代理及后端禁止的替换字符。勾选确认影响当前集团全部消息后才能提交。
- 缩短期限可能使既有正文立即到期，后续清理任务运行可能清空正文。有消息历史时服务端拒绝延长期限，页面在 409 时说明版本冲突和延长限制两种可能原因，不臆测具体原因。
- 保留期不属于单个会话。有效法务保全暂停正文／摘要物理清理，但不会改变到期正文的读取遮蔽。保存配置不会启动清理任务，不能恢复已清除的正文。审批引用仅记录，不核验外部审批。

## 版本写入与异常核对

1. 每次提交冻结原版本、天数、审批引用和身份上下文；发送 PUT 的 `expected_version`，不增加后端不存在的 request_id。发送期间冻结输入，禁止重复提交、查询和放弃。
2. 校验完整成功 DTO：期限、安全整数版本、默认字段约束、审批引用、审批人 UUID、带时区 RFC3339 时间及真实日历日期。PUT 另须绑定原版本加一、目标天数／引用和当前用户。
3. 网络异常、503、响应丢失、无效 DTO 和 15 秒超时转“结果待确认”。超时仅停止等待，不表示服务器未执行。此时不能直接重发，先 GET 核对服务器状态。
4. GET 仍为原版本时，允许按原版本、原天数和原审批引用重试。即使查询与重试间发生变化，服务器 CAS 仍拒绝旧版本，页面不会自动换成新版本写入。
5. GET 为原版本加一且期限／引用／登记人一致时，只表述“当前配置与本次提交一致”。仅凭当前配置无法独立证明由哪一次请求提交，不虚构请求幂等证据。更高版本或不同内容则提示核查审批与审计记录，重新填写并确认；不自动提交。
6. 400／409 清空可编辑的旧配置，必须刷新后重新确认；403／404 清空配置并禁用入口。401 或任职失效沿用认证重置，迟到的 GET／PUT 不恢复旧身份内容。
7. 关闭弹窗清空当前展示和表单，仍保留未知操作的原参数。手动切换任职、会话或退出时重开原待确认窗口；保留期配置与法务保全写入双向互斥，不能在另一项结果未知时新建管理操作。
8. 放弃核对需明确确认，并说明“不代表撤销服务器操作”；放弃后仍必须刷新配置。数据只保留在页面内存，刷新／强制退出后须另行核查服务器记录。beforeunload 发出离页提示，但不能保证所有浏览器展示原生提示或阻止离页。

## 验证证据

- 新浏览器测试先因“缺少租户设置入口”失败，再实现页面后通过。双向管理互斥断言先复现另一管理弹窗被打开，再加入 canOpen 保护后通过。
- 真实 Chrome 加载生产 HTML／JS，HTTP 边界注入成功、400／403／404／409／503、已提交后截断响应、持续无响应、非法 DTO、延迟 GET／PUT。验证固定请求字段、原版本重试、未知期间禁止编辑、当前状态核对及晚到响应隔离。
- 独立评审发现宽松 Date.parse 接受“1”和“2026-02-30”；普通 GET 失败用例先复现此问题，修正为严格格式和真实日期验证。新增普通读取、PUT ACK、待确认核对三条路径的异常审批时间用例，以及纳秒小数和 +08:00 合法时间。
- 真实生产 API／Outbox Worker、本地 HTTPS OIDC PKCE、PostgreSQL／Redis 和 Chrome：浏览器将期限改为 180 天、版本 1；数据库校验审批历史和允许审计各一条；有消息时延长至 366 天被拒绝并留下拒绝审计；另一租户仍为默认 365 天、版本 0。继续验证清理记录、保全操作、多设备实时通知及离线恢复；原有三条消息正文仍在，没有运行正文／摘要清理 Worker。
- 首次基线运行因旧环境文件指向旧端口而连接拒绝。检查 Docker 当前绑定后改用测试库 33099、Redis 33100，完整基线通过；没有为测试环境问题修改产品代码。
