## 运行配置

| 进程 | 显式启用配置 |
| --- | --- |
| API | IM_FILE_UPLOAD_ENABLED=true；已有IM_OIDC_ENABLED及完整OIDC配置；IM_DATABASE_URL；IM_FILE_SPOOL_DIR绝对路径；IM_FILE_S3_ENDPOINT／REGION／BUCKET／CREDENTIAL_SOURCE=environment／PATH_STYLE；IM_FILE_S3_ACCESS_KEY／SECRET_KEY |
| Worker | IM_FILE_WORKER_ENABLED=true；IM_DATABASE_URL；IM_FILE_WORKER_ID机器UUID；IM_FILE_SCAN_CONCURRENCY固定1；独立0700 SpoolDir；同名S3配置但凭据仅具备只读／版本查询；IM_FILE_QPDF_PATH／IM_FILE_CLAMD_SOCKET／IM_FILE_SCANNER_MANIFEST |

Worker角色须允许固定版本读取、版本列表和私有／版本能力预检，不允许PutObject/DeleteObject。专用MinIO有效只读账号已验证能扫描、写入被拒绝；其IAM不接受GetBucketAcl动作，AWS部署需另配置相应只读预检动作。运行时不创建bucket、不迁移数据库、不修改存储策略、不下载病毒库。

启动前预检000019相关表、私有且versioning有效的bucket、扫描进程及行为证据。Worker单扫描，恢复每轮有界100条，空闲／故障1～30秒退避；关闭信号取消外部I/O与续约。检测90秒；只允许失败结果用另5秒上下文登记，实际写入仍检验原120秒租约，迟到clean不能提交。
