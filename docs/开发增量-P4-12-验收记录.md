# P4-12 集团审计查询 API

## 范围与基线

基线 P4-11 `e33722d7ffa23ff00d19352ad76cecc0f439eb6a` / 草稿 PR #58；分支 `codex/p4-12-audit-query`，复用已附加隔离工作区。本次提供现有 `audit_events` 表的只读后台接口，接入生产 im-api；没有新增表、迁移或 Web 页面。

## 查询契约

- `GET /api/v1/admin/audit-events`，沿用可信认证与 `X-Acting-Membership-ID`，不接受客户端 tenant_id。仅当前有效集团管理员可查询本租户记录，组织管理员与普通人员不能查询租户全量审计。
- 可选 `action`：`^[a-z][a-z0-9_]{0,63}$`，精确匹配；合法但未登记的动作返回空数组。可选 `outcome`：allow 或 deny。省略筛选返回所有动作／结果；显式空筛选非法。
- 可选 `limit` 默认 20、范围 1～100，规范十进制整数；可选非空 `cursor` 最长 1024 字符。拒绝未知／重复／非法编码参数、请求体、非 GET 方法。无总数计算或无界查询。
- 响应为 `events` 数组与 `next_cursor`；字段为 id、actor_user_id、acting_membership_id、action、resource_type、resource_id、outcome、reason、occurred_at。bigint id 以十进制字符串返回，不经过浮点转换；resource_id 缺失时为 JSON null。空页为 `[]`，末页游标为空。
- 按 `(occurred_at, audit_events.id)` 倒序，明确按数据库 bigint 列排序；游标绑定租户、action、outcome、UTC 时间及正数 bigint ID。规范 Base64URL JSON 编码拒绝未知／重复字段、非规范时间／数字和越界值。游标不能代替权限，改筛选必须从首页重新查询。
- 每页为独立事务，不保证跨页共享快照；翻页期间新增或迟到提交的事件请刷新首页核查。本页查询审计在查询之后登记，故本页不含自身事件；无筛选或 action=audit_events_list 可看到以前查询的记录。

## 权限与审计一致性

- READ COMMITTED 在事务首条查询前显式设置；先锁执行任职，再按已有解析器检查并锁定租户、账户、任职、组织、法人及管理员授权。保持 member-before-tenant 顺序。
- 初次授权后再次用新时间检查，避免授权查询等待锁后沿用旧期限；查询后、审计 I/O 后再次复核期限。冻结、任职结束、撤权、授权过期不返回数据。
- 成功查询与 `audit_events_list` / allow / `listed_audit_events` 同事务提交；审计失败返回 503，无数据或游标。审计之后过期回滚允许事件，不把已失效查询登记为允许。
- 身份失败为 403；有效身份缺少集团授权为 404；非法查询为 400，认证令牌无效为 401。数据库内部错误不返回给调用方，响应禁止缓存。
- 查询审计表明接口授权及数据查询，不证明记录已被客户端接收或由用户逐条阅读。

## 交付边界

本次查询应用已登记的 `audit_events`，不包含 `policy_decision_events` 的匹配规则细节、消息正文、审批单正文或清理批次明细。没有新增 Web 审计页面、导出、时间范围／执行人筛选、审计保留期物理清理或防篡改存储；数据库直接改写、外部日志和客户环境联调不由本接口覆盖。未启用正文／摘要清理 Worker。索引沿用既有租户／时间索引，大规模筛选容量仍待压测。本地自动验证不代表生产验收；草稿 PR 不代表合并或部署。
