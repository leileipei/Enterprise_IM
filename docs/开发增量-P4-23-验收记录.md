## 已实现并逐项验证

- `000020` 增加正式 text/file 消息类型及单文件关联；来源必须为原租户、会话、上传人、任职。关联不可删除，同文件只绑定一次；已有证据时拒绝 Down。
- 单聊／群聊原子写入消息、绑定、幂等、序号、Outbox 和成功审计；规范化文件摘要使用封存指纹。删除文件或清空 caption 后仍可重放原 ACK，退役后拒绝旧键。
- 严格 HTTP 类型解析、UTF-8／NULL／混合字段／重复键边界；显式测试装配允许 file，生产装配保持关闭。
- `message_format=typed_v1` 返回 caption 和最小附件卡片，实际大小为十进制字符串，download_available=false。旧格式只显示“附件消息（当前客户端不支持查看）”。文件不可用时隐藏内容元数据，权限／期限遮蔽整项；附件 caption 和文件名不进入文本搜索。
- 正文 Worker 沿用 text_body 清理 caption，包括空 caption；摘要 Worker 同事务、同时间戳退役消息摘要、幂等摘要、附件指纹，精确验证返回文件消息集合；有效会话保全暂停清理／退役。
- 真实 PostgreSQL 多连接验证：相同键8次发送仅1次新建／7次重复；不同键竞争同文件仅1次成功；删除、配置撤销／降限、用户冻结、任职期限、群移除、规则跨等待失效、五种写入故障及重放／退役竞争维持写入、序号和配额不变量。
