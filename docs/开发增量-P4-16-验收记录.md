# P4-16 按资源定位管理审计

## 基线与范围

基于 P4-15 `b50cfca97c2ec3d710a4a079dbace8e5e552858d` / 草稿 PR #62；分支 `codex/p4-16-audit-resource-filter`。扩展管理审计 API 和 Web 弹窗，组合资源类型、资源 ID 与既有执行人／时间／动作／结果条件；不新增迁移或写入动作。

## 查询契约

- `GET /api/v1/admin/audit-events` 新增可选 `resource_type` 和 `resource_id`。类型为 1～64 个小写字母、数字或下划线，以字母开头；ID 为完整 UUID，大小写等价。
- 类型可单独查询；指定 ID 时须同时指定类型。省略不限；显式空值、重复参数、非法类型／UUID 或只传 ID 返回 400。
- SQL 精确匹配类型与 UUID；类型单独查询包含资源 ID 为 null 的事件，指定 ID 后仅返回该类型下非 null 的匹配事件。不同资源类型拥有相同 UUID 时不会混入结果。
- 当前可信身份的租户限制始终存在；资源是历史审计元数据，不查询其当前存在性。当前租户未登记对应审计的资源条件返回空数组，其他租户独有条件同样返回空数组；已删除资源的历史审计仍可查询，不改变授权范围。
- 游标绑定规范化后的资源条件和既有租户／执行人／时间／动作／结果。更换、取消类型或 ID 后不可复用旧游标；大小写等价 ID 可继续翻页。未筛选资源时省略新增游标字段，旧版格式继续兼容。
- 保持任职优先锁顺序、READ COMMITTED、逐页集团管理权限和新鲜时间复核、查询审计原子提交及提交前授权检查。

## Web 行为

- 弹窗增加资源类型／资源 ID 文本输入，提供 conversation、tenant 示例及成对查询提示。类型可留空查询全部，ID 可留空查询该类型全部事件。
- 非法类型、只填 ID 或非法 UUID 在页面提示，不发起请求；输入变化立即清空记录、游标和已见游标集合，递增请求代次。
- 请求携带当前类型和小写 UUID，原始输入快照与代次防止迟到响应污染列表；类型与 ID 变化分别验证。关闭、Esc、任职变更清空字段，权限失效禁用输入。
- 响应类型不匹配、ID 不匹配或指定 ID 后出现 null，均拒绝整页并清空。异常样本保留合法 ID 顺序和时间顺序，拒绝不依赖其他校验。
- 保留 bigint／原始时间精度、微秒边界、循环游标检查、15 秒超时及未知结果写入核对保护。

## 验证记录

- HTTP 新参数用例先返回 400；数据库资源筛选先错误返回 null 资源事件 15，而不是目标事件 14；只提供资源 ID 在旧实现被接受。以上失败已实际观察。
- 后端目标通过：跨类型相同 UUID、跨租户相同 UUID、跨租户独有资源、NULL／类型单独筛选、未知类型空结果、大小写 ID 续页、游标更换／取消资源拒绝，以及全部既有筛选组合。查询审计计数核对 6 条成功读取事件。
- Chrome 使用生产 HTML／JS，资源输入用例先因缺少控件失败；实现后 21 条精确资源记录两页通过。类型单独查出 23 条并包含未指定 ID；组合执行人、时间与允许结果查出 11 条。
- Chrome 验证非法输入不请求，资源类型／ID／null 响应逃逸拒绝，资源类型与 ID 各自变化后的迟到响应不能恢复列表，未知类型空记录和关闭清空。原有时间／执行人、精度、游标循环、异常 DTO、超时和身份／权限回归继续覆盖。
- 双生产 API 按 tenant／实际租户 ID 组合已有条件并跨节点续页；修改资源 ID 后旧游标拒绝。真实 OIDC 浏览器先读取审计元数据快照，再按实际租户资源与执行人／时间筛出允许、拒绝事件；仍核对 3 条成功查询审计。

## 边界

仅查询在线库已登记 audit_events，不代表该资源当前存在、当前用户可操作资源，或外部审批已核验。仍要求集团管理员；未新增组织级资源审计授权。跨页无共享快照，新事件需刷新核查，查询本身产生审计。姓名／组织筛选、导出、规则命中细节、防篡改及生产容量优化留待后续；文件授权与扫描、搜索及 LDAP／AD 等原 P4 企业配套范围仍未完成。客户环境及生产验收未完成，未启用正文／摘要清理 Worker，草稿 PR 不代表合并或部署。
